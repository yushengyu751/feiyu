# 大肥鱼 · 手机里的 AI 伴侣（Android）

一个独立的小 APK：不依赖电脑、不依赖服务器中转，聊天记录和记忆都存在手机本地。

- 体积约 0.3 MB，Android 7.0（API 24）及以上
- 用自己的 DeepSeek API Key，按量计费
- 没有任何账号系统，也不上传你的聊天记录
- 也没有服务器

## 它是什么

一款AI聊天软件：

- **有记忆，但是会淡忘**：说过的内容按时间从「清晰」逐级淡到「只剩印象」，你再提起时会自动加深一级
- **随着聊天的深入关系不断变化**：记录关系阶段（你可以自己选择你们的关系）、信任度和此刻情绪，但都不写死，跟着你们实际怎么相处走
- **会写日记**：把一天里聊过的整理成一篇日记，再从里面抽出长期记忆和可复核的知识卡
- **说话方面**：有人设分段（身份 / 场景 / 说话方式 / 禁止 / 示例 / 记忆），可以自己改

## 安装

1. 下载 `dafeiyu.apk`
2. 手机上点开 → 允许「安装未知应用」→ Play Protect 提示时选「仍要安装」（自签名包属正常现象）
3. 打开后进「设置 → 连接」，填自己的 DeepSeek API Key

不填 Key 也能打开、能翻记录，但发消息会报错。

## 隐私

- 聊天记录、日记、记忆、Key 全部存在 App 私有目录（WebView 的本地数据库）
- 消息只发给你自己配置的接口（默认 `api.deepseek.com`），不经过任何第三方服务器
- 换手机或重装前，用「设置 → 存储 → 导出备份（ZIP）」导出，换机后导入
- 可以导入json和zip数据，他们里面是你的聊天记录啥的

## 已知限制

- 不会主动联网检索（你发链接它可以读正文）
- 除你主动发送的图片外，看不到相册和手机
- 数据只在本机，卸载即删除；没有云端同步
